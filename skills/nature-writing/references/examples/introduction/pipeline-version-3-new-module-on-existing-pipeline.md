# Pipeline Version 3: A New Module in an Existing Approach

Establish the inherited pipeline before describing the new component.

The local Deep Snake notes use contour processing to illustrate this sequence: begin with a contour-refinement task, identify the closed structure of the representation, and explain why a compatible operation is introduced. The contribution is localized to the part of the pipeline that changes.

A useful paragraph sequence is:

1. Attribute the existing approach and describe the input and output.
2. Identify the component whose behavior limits the task.
3. Explain the replacement or addition and the structural reason for its design.
4. Describe how information passes through it.
5. Point to a comparison that tests the claimed benefit.

Do not imply that the surrounding pipeline is new when it is inherited. Keep performance statements conditional on the actual evaluation.
