# Introduction Version 2: Application First

Use this opening when readers already understand the task.

Begin with the capability an application requires. Move quickly to the constraint or failure that motivates the study. Explain the connection between the application and the research question; avoid a generic list of fields.

```latex
% Practical need: [what the application must accomplish]
% Research constraint: [why current approaches are insufficient here]
% Scope: [which part of that constraint this study examines]
```
