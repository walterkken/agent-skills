# Introduction Version 1: Task Before Application

Use this opening when the intended reader may not know the task.

First specify what the task consumes and produces. Then explain where that capability matters. Keep the application list short enough that it clarifies motivation rather than distracting from the research problem.

```latex
% Task: [infer a defined output from specified observations]
% Application: [a use case that depends on that output]
% Transition: [the condition that makes the task difficult]
```

The local notes use object pose estimation to illustrate the distinction between defining a geometric output and motivating its applications. This is a summary of that instructional role.
