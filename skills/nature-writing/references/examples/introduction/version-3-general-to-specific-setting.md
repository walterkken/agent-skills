# Introduction Version 3: General Need to Specific Setting

Use this pattern when a familiar task is studied under a less familiar condition.

1. Establish the broad capability and its practical relevance.
2. Narrow the discussion to the available inputs and required outputs.
3. Identify the constraint introduced by that setting.
4. Make the remaining research question explicit.

The local pose-estimation notes distinguish the general need to recover spatial pose from the specific case of doing so with a single RGB image. The writing lesson is to narrow the setting before discussing methods.

```latex
% Broad need: [capability and use]
% Setting: [input availability, target output, and constraints]
% Gap: [difficulty specific to this setting]
```
