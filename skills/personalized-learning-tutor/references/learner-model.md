# A provisional learner model

“Language system” here means the words, examples, distinctions and reasoning habits a learner currently uses to explain a subject. It is a working aid for teaching, not a psychological diagnosis or validated personality classification.

## Evidence to retain

| Aspect | Useful evidence | What not to assume |
| --- | --- | --- |
| Vocabulary | Terms the learner uses correctly or asks to unpack | Repeating a term proves understanding |
| Familiar anchors | Experiences or examples they explain accurately | Their occupation implies a particular hobby or skill |
| Prerequisites | A solved example, explanation, or explicit statement of familiarity | A supplied advanced document establishes mastery |
| Reasoning order | An explicit request for mechanism first, example first, or proof first | One successful format must be used forever |
| Formalism | Comfort with notation shown in the current task | Short or informal writing means weak mathematics |
| Friction | A specific incorrect step or question | Confusion means low general ability |
| Goal | What they want to be able to do next | Every user wants an exam or long lesson |

Track confidence through evidence labels rather than invented precision: explicit preference; demonstrated on this task; tentative inference; unknown. Avoid numeric ability scores inferred from prose.

## Minimal working note

Retain only what affects the next explanation:

- Goal and current concept.
- Familiar terms/examples supported by specific input.
- Prerequisites demonstrated or still uncertain.
- Present misconception or sticking point, if any.
- Current request about length, notation and interaction.
- Next teaching adjustment and what evidence would change it.

Do not write a biography, copy full conversations, or extract sensitive traits. Usually keep this note within task context. If the user asks to save a learning profile, summarize it in ordinary language and use the host's supported authorized storage route.

## Resolve conflicting evidence

Prefer the current explicit instruction, then recent task-specific demonstration, over old generic preferences. Someone can want a simple introduction today and a complete proof tomorrow. A learner may know physics but be new to its mathematical formalism.

When multiple people contribute, attribute statements only where the source is clear. Do not merge different speakers into one profile. If speaker identity changes the explanation and cannot be determined, ask a brief clarification.

Use the learner's responses as opportunities to revise your assumptions. Present an uncertain anchor as an example that can be changed, not as a fact about the person.
