# Technical Challenge Version 3: A New Task Setting

When direct prior solutions are absent, organize the challenge around what a successful solution must accomplish.

Define the task first. Then separate the obstacles, explain their causes, and identify which existing assumptions fail in this setting. Each obstacle should correspond to a requirement that the method or evaluation will later address.

A reusable structure is:

```latex
% Goal: [required inference or capability]
% Information constraint: [what observations are unavailable]
% Ambiguity: [different explanations compatible with the input]
% Output requirement: [what must be represented or quantified]
% Response: [which part of the method addresses each requirement]
```

The local notes use inference from a single image as a teaching setting. Keep numerical claims and comparisons out of the manuscript until its own sources support them.
