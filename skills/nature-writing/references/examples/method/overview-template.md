# Method Overview Template

The overview should orient readers before they encounter individual components.

1. Define the available inputs and required outputs.
2. Name the central change or representation.
3. State the main processing stages in order.
4. Use a figure when it makes their relationship easier to follow.
5. Map the stages to the subsections that explain them.

The local notes illustrate this role with several separate topics, including dynamic representations, contour refinement, and pose estimation. These examples show possible ways to organize an overview; their technical claims should not be combined into a single method.

```latex
% Setting: [inputs, outputs, and relevant conditions]
% Central design: [what the method introduces or changes]
% Stage 1: [initial representation or transformation]
% Stage 2: [main processing operation]
% Stage 3: [prediction, reconstruction, or decision]
% Navigation: [figure and actual subsection labels]
```

Use labels from the manuscript being edited. Remove stages that the method does not contain, and defer detailed hyperparameters to the appropriate subsection.
