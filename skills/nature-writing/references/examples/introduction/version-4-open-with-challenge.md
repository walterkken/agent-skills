# Introduction Version 4: Put the Challenge in the Opening

Use this pattern when readers can understand the relevant limitation with little background.

The opening should connect a practical need, the basic mechanism of a prior approach, and a concrete failure condition. If that connection requires substantial explanation, develop it over several paragraphs instead.

The local examples make two distinct connections:

- Reconstruction: limited visual texture can make correspondence-based evidence less informative.
- Segmentation: an intermediate region representation can constrain what later processing recovers.

The examples teach how to link a limitation to the method's mechanism. They do not establish that every method in either field has that limitation.

```latex
% Application: [required capability]
% Existing approach: [mechanism relevant to the argument]
% Failure condition: [where and why that mechanism struggles]
% Study focus: [precise issue addressed here]
```
