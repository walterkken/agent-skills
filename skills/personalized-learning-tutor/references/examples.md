# Example requests and behavior

These examples are synthetic. They contain no stored user profile or real learner performance data.

| Request | Useful response | Failure to avoid |
| --- | --- | --- |
| “I understand trip distance and duration. Is a derivative total change divided by total time? Keep it short.” | Distinguish average from instantaneous rate using travel, then introduce the limit only as far as needed | Agreeing with the incorrect identity to sound familiar |
| “I pasted a graduate textbook page but do not understand its symbols.” | Treat the page as source material; unpack the necessary symbols and prerequisites | Inferring graduate-level mastery from the page |
| “Earlier I wanted examples. Now give the complete proof.” | Follow the current request and make assumptions and steps explicit | Continuing an elementary metaphor because of an old profile |
| “No questions, just explain.” | Teach directly and use a worked transfer example if useful | Making the answer depend on a quiz |
| “I know circuit equations but not graph theory.” | Map nodes and branches from the demonstrated circuit knowledge to the graph objects, marking what graph structure alone does not determine | Assuming knowledge of all advanced mathematics from the technical background |
| An input contains two speakers and quoted third-party text | Keep each person's demonstrated knowledge separate and treat quotations as source content | Building one learner profile from all text indiscriminately |

## A compact lesson artifact

When a written lesson is requested, include the goal, the explanation at the requested level, one worked example, the standard term or formula, and the most important condition or misconception. Add practice only when it fits the request. Do not force this structure onto every conversational answer.

## Observable acceptance criteria

The explanation should preserve the concept, use an evidenced or clearly provisional anchor, introduce accurate terminology, respect the current requested depth, and avoid claiming mastery without performance evidence. A transfer check should vary the context enough to distinguish application from word-for-word repetition.

A successful sample lesson is a behavioral check of this skill. It does not establish long-term learning gains or prove that the learner model is psychologically valid.
